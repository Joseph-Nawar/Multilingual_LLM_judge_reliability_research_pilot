# Manuscript draft

`main.tex` is an ACL review-style manuscript draft for **Multilingual LLM-Judge Reliability Under Evolving Conversational Constraints**. It contains initial versions of the requested introduction, questions/hypotheses, related work, dataset construction, experimental design, baseline implementations, evaluation methodology, and ethical considerations/limitations. It also records the exploratory development and Multi3WOZ findings separately and leaves every locked-study result explicitly pending.

`references.bib` contains the cited works. Venue metadata for the ACL Anthology papers and title/authors for the arXiv preprints were checked against the official ACL Anthology and arXiv records linked in that file. The preprints are labeled as such in the bibliography and should be rechecked before submission.

The draft expects the official ACL `acl.sty` style package and bibliography style to be available when compiling; those files are not vendored. No TeX engine is installed in the authoring environment, so this version has not been compiled to PDF. The repository test suite is independent of the manuscript.

This is an initial manuscript draft, not a submission-ready paper. Replace the anonymous author placeholder only after the target review format is chosen. Do not insert locked results before independent bilingual validation, adjudication, and the hash-bound freeze and run are complete. No private scenario text, canonical labels, review records, or locked outputs belong in this directory.
